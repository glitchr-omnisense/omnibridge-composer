# Stubs

A package declares stub providers in `extra.omnibridge.stubs`: class names,
autoloaded from that package (its psr-4, psr-0 and classmap; never its `files`).
They run after every `composer dump-autoload` (so after install and update), and
once more after the patches when those changed a file.

```php
interface StubInterface
{
    public function getName(): string;                         // the subdirectory: Entity, Repository...
    public function generate(StubContext $context): iterable;  // relative path => content
}
```

`StubContext` gives the project directory, the vendor directory, the declaring
package's directory and name.

The engine writes every provider's files under
`vendor/composer/omnibridge/stubs/<name>/`, rewriting a file only when its content
changes and removing what no provider returns any more. No autoloader reads that
directory: a stub is for an IDE and static analysis, never a definition at run
time. A provider must be deterministic - the same tree gives the same bytes, no
date, no absolute path - which `composer omnibridge:stubs --check` verifies in CI.

## AbstractStub

The generic generator: it mirrors the classes of a source namespace under a target
namespace, for a package that, at run time, makes each `Target\X` an alias of
`Source\X` unless the application defines `Target\X` (omnibase's `Base\` and
`App\`):

```php
final class EntityStub extends AbstractStub
{
    public function getName(): string { return 'Entity'; }
    protected function getSourceNamespace(): string { return 'Base\Entity'; }
    protected function getSourceDirectory(StubContext $c): string { return $c->packageDir.'/src/Entity'; }
    protected function getTargetNamespace(): string { return 'App\Entity'; }
    protected function getApplicationDirectory(StubContext $c): ?string { return $c->projectDir.'/src/Entity'; }
}
```

One stub per plain class (not abstract, final or readonly; not an interface, a
trait or an enum, read with PHP's tokenizer) whose relative path has no file in the
application directory:

```php
namespace App\Entity;

/** Generated by omnibridge/composer (...EntityStub) ... */
if (!class_exists('\App\Entity\User')) {
    class User extends \Base\Entity\User {}
}
```

`render()` can be overridden for another form.
